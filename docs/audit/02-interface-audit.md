# Интерфейс Saldoza 1.5.123

Проверка тестовой PWA с пустым профилем и после заполнения остатков.

| Пользовательская задача | Что обнаружили и изменили |
| --- | --- |
| Понять, с чего начать | У нового профиля была ипотека 55 000 ₽ и заданный резерв 500 000 ₽. Теперь начальные значения нулевые. Главная объясняет смысл дневного лимита и ведёт одной кнопкой к вводу остатков. После сохранения открывается главная. |
| Решить, когда купить вещь | В расчёте покупки появилась кнопка переноса в календарь. Название и сумма переносятся в форму, дата доступна для редактирования. План превращается в расход только после отдельного подтверждения при наличии денег. |
| Посмотреть прогноз | Список дней и дополнительные настройки свёрнуты. Можно отдельно проверить изменение ежедневных трат и задержку доходов. Сценарий не записывает операции. |
| Работать с несколькими источниками дохода | Дополнительные поступления находятся в раскрываемом разделе календаря. Для зачисления пользователь явно подтверждает поступление за конкретный месяц. |
| Учесть рассрочку | В регулярном платеже можно указать остаток беспроцентного долга. Последний платёж равен остатку, после него резервирование прекращается. |
| Прочитать экран крупнее | Возвращено пользовательское масштабирование. У активной вкладки есть программно определяемое состояние. |
| Снова открыть ввод операции | Проверены два последовательных открытия с вводом текста. Для iPhone предусмотрена диктовка клавиатуры. Реальный звук и поведение iOS требуют проверки на устройстве. |
| Запустить приложение без ошибки | Удалено обращение наблюдателя размеров к отсутствующему элементу, из-за которого выполнение останавливалось до регистрации service worker. |

## Проверки

Chromium с ширинами 320, 390 и 1100 CSS-пикселей. Сценарий tests/browser/ux-flows.cjs проверяет все шесть вкладок, отсутствие горизонтального переполнения, ввод остатка, планирование покупки, подтверждение расхода, дополнительный доход, повторное открытие ввода и сохранность после перезагрузки. Запуск из корня проекта с установленными Playwright и Chromium командой `node tests/browser/ux-flows.cjs`. При использовании системного Chromium укажите путь в CHROMIUM_PATH.

В Chromium на ширине 390 px axe-core 4.10.3 не выявил автоматически определяемых нарушений по тегам WCAG 2 A, AA и 2.1 AA на шести основных вкладках в исходном состоянии. Регрессионные проверки в Node включают рассрочку 2 500 ₽ с платежами 1 000, 1 000 и 500 ₽.

## Открытые вопросы удобства

Семейные подписи «У жены», отдельная вкладка кредитов и два типа зарплатных выплат предполагают конкретный семейный сценарий. Для универсальной версии нужны отключаемые модули и настраиваемые участники. Проверки с новыми пользователями и с VoiceOver на физическом iPhone ещё не проводились.
