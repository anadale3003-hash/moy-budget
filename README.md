# Мой бюджет

Мобильное PWA-приложение для учёта семейного бюджета.

Публикация: GitHub Pages, ветка `main`, папка `/`.

**Важно:** не добавляйте в публичный репозиторий резервные копии с персональными финансовыми данными. Данные приложения хранятся локально в браузере телефона; при переходе с другого домена их нужно перенести экспортом и импортом из настроек приложения.

Исправления начинаем в отдельной ветке от актуальной main. Для просмотра запускаем
`python -m http.server --bind 127.0.0.1` из рабочей копии и открываем preview.html.
Тестовая страница содержит экспериментальные функции и собственный ключ данных.
Переносим в index.html только проверенные изменения. Версию обеих страниц сверяем
с version.json. Перед выпуском запускаем `python tests/budget_browser.py`
(Python, Playwright и Chromium). Публикация в main — после согласования.
