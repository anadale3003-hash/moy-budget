# Мой бюджет v1.5.8

Мобильное PWA-приложение для учёта семейного бюджета.

Публикация: GitHub Pages, ветка `main`, папка `/`.

**Важно:** не добавляйте в публичный репозиторий резервные копии с персональными финансовыми данными. Данные приложения хранятся локально в браузере телефона; при переходе с другого домена их нужно перенести экспортом и импортом из настроек приложения.
